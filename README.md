# 🎴 My Profile Card
![Profile Card Screenshot](preview.jpg)

A clean, responsive, and modern personal profile card built with pure HTML and CSS. This project displays key professional details, skill tags, and quick action buttons for personal branding and developer portfolios.

---

## 🚀 Live Demo

🔗 ** https://codewithagares.github.io/my-profile-card/

---

## ✨ Features

- 👤 **Profile Header**: Avatar placeholder / profile image with custom styling.
- 🏷️ **Skill Tags**: Interactive tags highlighting tech skills (`HTML`, `CSS`, `Git/GitHub`).
- 🔗 **Action Buttons**: Quick links to GitHub profile and contact email.
- 📱 **Responsive Design**: Clean layout optimized for both desktop and mobile screens.
- 🎨 **Minimalist Aesthetic**: Smooth borders, balanced typography, and soft pastel accent colors.

---

## 🛠️ Built With

- **HTML5** – Semantic structure and layout
- **CSS3** – Modern styling, Flexbox layout, and custom button designs
- **Git & GitHub** – Version control and hosting via GitHub Pages
